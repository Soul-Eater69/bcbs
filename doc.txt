**Description**

As an IDP user,

I need Engagement Requests with zero linked themes to be excluded from the ingestion process,

So that only valid and relevant Engagement Requests are displayed under Similar Engagement Requests.

Currently, some Engagement Requests are being ingested into the AI Search index and Cosmos DB even though they have no linked themes. As a result, these ERs are returned as similar recommendations in the UI, but the **View Linked Themes** count is displayed as zero.

Because the similarity workflow depends on the themes associated with an Engagement Request, an ER without any themes does not provide useful information for comparison. The ingestion process should therefore confirm that an ER has at least one valid linked theme before storing it in AI Search and Cosmos DB.

If an ER has no linked themes, it should be skipped during ingestion and should not appear in the Similar Engagement Requests results.
