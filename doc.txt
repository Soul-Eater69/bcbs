6. Any identifier that would help identify the value card, like a specific naming convention
There is no consistent naming convention today.

No file is named “Value Card”.
Idea Card or Value Case appears in the file name for 15 of 100 ERs (Finalized only), or 90 of 236 ERs when Working is included.
Without a convention, value cards can’t be reliably identified by file name. A naming convention would be needed (requested from the business).

Finalized + Working: median 3.1K, 90th percentile 17.8K; 16 ERs exceed 24K.
The few ERs above 24K would need file prioritisation or trimming. Counts use the GPT-5 mini tokenizer on text only; images are not included.
