1. The regex may be missing files

\b treats underscores as part of a word, so names like I0102679_VC_Grievance or 2026_VC.xlsm don’t match. Also check folder paths, not just file names:

python
pat = r"(?<![A-Za-z])VC(?![A-Za-z])|value\s*card|valuecard"
hits = m[m["name"].str.contains(pat, case=False, regex=True) |
         m["path"].str.contains(pat, case=False, regex=True)]
print(len(hits), hits["er"].nunique())
print(hits[["er", "name", "extension"]].head(30).to_string())
2. Identify value cards by content instead of name

The 4 templates you found (VC 1099 Tax Template – ClassicHEM/SlimHEM) are the best lead. If value cards are filled-in copies of a template, they’ll share its structure even when renamed:

For .xlsm/.xlsx: compare sheet names and header cells against the template’s. Pulling just the sheet names with openpyxl (read-only) is cheap, even across all 1,600 spreadsheets.
For .pptx: compare slide titles or layout names.
python
from openpyxl import load_workbook
wb = load_workbook(path, read_only=True)
print(wb.sheetnames)   # compare with the template's sheet list

If many workbooks share the template’s sheet names, you’ve found the real value cards, and the result answers Q6 better than any naming rule.
